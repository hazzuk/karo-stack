# Contributing

Thank you for your interest in contributing to the karo-stack.

The best ways to help the project include the following:

- :lucide-message-square-more: [Providing feedback](https://github.com/hazzuk/karo-stack/discussions/new/choose)

- :lucide-bug: [Reporting bugs](https://github.com/hazzuk/karo-stack/issues)

- :lucide-file-plus: [Improving the docs](https://github.com/hazzuk/karo-docs/)

- :lucide-bolt: [Creating a karo-custom repo](../custom/index.md)

- And sharing the project with others

!!! info "Contributing code"

    Code contributions are welcome!
    You'll need experience with one or more of the project's core technologies
    (Linux, Ansible, Docker, Golang, Bash).

    It's always best to reach out first,
    whether you have a change in mind or are just available to help out.
