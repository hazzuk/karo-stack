# About

The karo-stack is an open-source project developed by me,
[hazzuk](https://github.com/hazzuk/) (aka Hazza) 👋.

I'm a British Software Engineer, who
after self-hosting for nearly a decade,
wanted to build his ideal homeserver software stack.

Something lightweight, declarative, and empowering.

My philosophy with software development is pretty simple,
build what you want to use.

As such, I've been running the project on my personal homeserver since December 2025,
and fully intend to keep on improving it for many years to come.
